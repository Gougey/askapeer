Which selected tab reads fastest?

Andy’s note was that the selected tab in the bottom bar isn’t obvious enough. Five treatments below, each on a real 430px bar with the app’s own icons and spacing. Tap the tabs — the point is how quickly your eye finds the selected one, which a screenshot can’t tell you. The Ask button is untouched throughout.

Two things worth knowing before you pick

  • Colour alone isn’t allowed to be the only signal. The style guide (§9.2) says state can’t rest on colour by itself, and today’s treatment does exactly that — A is the same icon in a different hue. Every other option adds a shape, so they are the more correct ones as well as the louder ones.
  • Red is spoken for. Spark red belongs to the Ask button and the wordmark and cannot be borrowed for a selected state, so navy is what’s available. That is why none of these turn the tab red.
  • B matches what we just chose elsewhere. The tab headers on Create, Search and Activity now use a filled navy segment, so the filled lozenge would make one idea — “this is the one you’re on” — look the same everywhere in the app.

Adrian’s view is that the current treatment is fine; Andy’s is that it isn’t obvious enough. Both can be true — it reads clearly on a bright desk monitor and less so on a phone at arm’s length outdoors, which is where it will mostly be used.
